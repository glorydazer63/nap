## Overview
_From the Internet_

Google Lighthouse is a free, open-source, automated auditing tool developed by Google to improve the quality and performance of web pages.  It runs a series of tests against any web page, public or requiring authentication, and generates detailed reports with actionable insights for optimization.

## Install
Run Lighthouse as a browser extension. Typically use a browser like Google Chrome or Firefox, as the App Store containing extensions are contained within.

- search for Google Lighthouse, or SEO
- install it into your browser (whether on mobile or desktop/laptop)

## Usage
- Now, go to the URL of the website you require to run a Lighthouse audit.
- Choose the Lighthouse extension from your browser. 
- Run the Lighthouse report, generate the result.
