## All about Flowershow
Researching static website tools back in 2025, I discovered this boutique web portal application that integrates to a Obsidian-Flowershow-Vercel model.

What this means is that you can easily transition your localised notes and pages content directly online in a matter of minutes without the pain that is usually associated with creating a website and all the intricacies that go with it.

### Flowershow Plugin on Obsidian
To publish directly onto the web via Obsidian, You would use the Flowershow plugin to make this possible.

Flowershow requires a Personal Token, which locks into the client's website. The token is embedded into the plugin.

### FlowerShow Dashboard
Once a client signs up for Flowershow, the configuration is administered through a very easy to manage dashboard. I will expand on the Dashboard details in a separate post.

Flowershow requests that you login either via a GitHub or Google account. I would suggest GitHub because once you do, you have direct access to their Discussions platform, which can be integrated into the static website via the above Dashboard. 

The Dashboard also determines whether you want to publish to a free tier FlowerShow online site (like this one), or if you decide on the premium plan (which is US$5.00 a month), then you get access to everything, including being able to use a customised domain.
