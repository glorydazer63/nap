## Implementation Steps

#### Do you require a customised domain name?
1. If no, then a free domain name will be allocated by Flowershow to enable an online presence.
2. If yes, then the client can arrange this themselves. Find a suitable Domain Registrar and search for a name you'd like to use.
    - be aware of the annual registration cost. These will vary between Registrars. 
    - note, you will only require a domain registration. You won't require web hosting, as your website data is being passed off to the Flowershow - > Vercel ecosystem. 
    - your domain once registered becomes a placeholder only. 

#### Do you require an email based on your customised domain? 
1. If no, you can use free emails like Google, Outlook, Tutamail or ProtonMail.
2. If yes, then once your domain has been secured, you will need to pay for web hosting because email is a service they provide. This could cost approximately US$60 to 70 a year. If the cost is prohibitive, go with option 1 and use a free email if branding is not an issue for you.

#### Do you require a standard front page with a basic image, banner, logo or a hero image? 
1. Standard images typically reside anywhere on the page.
2. A hero image typically sits at the top of the front page and spans the entire width. Many WordPress sites display an example of this. 

There are pro and cons of using a hero image.
- It's great for commercial branding but can be a bit overkill.
- Getting the visual and pixel dimensions correct can be trial and error.
- Image size can be detrimental to load speed when initially entering the website, depending how large the image size is.
- Hero images are not supported using the **Retype** project.

The Flowershow dashboard makes it easy to set up either or option.
