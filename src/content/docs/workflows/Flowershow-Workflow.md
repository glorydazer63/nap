## All about Flowershow
Researching static website tools back in 2025, I discovered this boutique web portal application that integrates to a Obsidian-Flowershow-Vercel model.

What this means is that you can easily transition your localised notes and pages content directly online in a matter of minutes without the pain that is usually associated with creating a website and all the intricacies that go with it.

### Setting Up
Creating a Flowershow instance requires signing up via the [Flowershow App](https://flowershow.app/). It's best to create a GitHub account (if you don't already have one), it's optional. Even though the latest version of Flowershow doesn't require GitHub, there are still benefits to having one, including the ability to dovetail into things like GitHub's Discussions, which is a commenting engine.

Instead, you can also create a Flowershow account using a standard email account.

- Click the Sign In button
- Sign in with standard email account
- Flowershow will send you a sign-up code to your email address to activate your account.
- Once you have access to the basic intro screen, you will have three options to create your website.
  - Blog
  - Docs
  - Wiki
- From here, the Flowershow Dashboard (details below) is presented where you can then configure the various elements to build your initial site layout. 
### Flowershow Plugin on Obsidian
To publish content directly onto the web via Obsidian, You would use the Flowershow plugin to make this possible.

Flowershow requires a Personal Token (PAT), which locks into the client's website. The token is created from the Flowershow Dashboard User Settings (icon top right corner), which you then embed into the plugin.

### FlowerShow Dashboard
Once a client signs up for Flowershow, the configuration is administered through a very easy to manage dashboard. I will expand on the Dashboard details in a separate post.

The Dashboard also determines whether you want to publish to a free tier FlowerShow online site, or if you decide on the premium plan (which is US$5.00 a month), then you get access to everything, including being able to use a customised domain.
